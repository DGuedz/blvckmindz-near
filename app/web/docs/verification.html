Run the checks yourself

From a clone of the public repository, use the prerequisites and installation steps in the README. The following verification command reads network evidence; it does not send a payment.

cd app
npm run verify:live -- ../evidence/live-runs/b19d4dcf-c5fb-4f06-8a6d-52820cd78cd7.json
