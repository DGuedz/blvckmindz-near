BLVCK MINDZ × NEAR / Architecture

A small, bounded testnet payment engine.

The interface is public. Signing state remains on the operator server.

Three operational layers

Vercel · interface
Hosts the participant sheet, motion, documentation and selected public evidence.
Hostinger VPS · bounded engine
The API proxy connects to a service with dedicated users, resource limits and persistent run history. It signs only for the isolated testnet demonstration.
NEAR testnet · execution
The rights contract, project test token, batches and transfers provide the execution evidence.

The demo no longer depends on the founder’s Mac. The VPS is shared infrastructure and has no demonstrated failover guarantee.

Solana and NEAR

The optional network portal shows an earlier, independent Solana devnet payment. It uses a different ledger and allocation. It does not move funds between Solana and NEAR. Cross-chain settlement is planned.

Submission and maintenance

The NEAR integration builds on earlier BLVCK MINDZ catalog and Solana work, disclosed in the repository. Hosting migrated on 15 November; navigation and documentation were refined afterward. This documentation does not claim those later changes were present at the submission deadline.
