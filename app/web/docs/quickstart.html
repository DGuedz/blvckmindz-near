BLVCK MINDZ × NEAR / Try the demo

From a filled sheet to a receipt.

No wallet setup is needed for the sponsored, fixed sample. All visitors share a limited execution budget, shown in the demo.

1. Simulate the split

Open the recording template. It contains an example ISRC, a 2.00 payment and contributor weights of 70/30. Select Simulate split. The motion follows the sheet, agreement, split and result. No tokens move.

The label receives 40%. The remaining 60% is divided 70/30, giving final shares of 40%, 42% and 18%.

2. Distribute on testnet

Select Distribute on testnet. The engine reserves and funds an invoice, approves the fixed sample, schedules the transfers and checks the network evidence. Arbitrary edited payouts are refused; editing the simulation does not authorize a different live payment.

3. Check what arrived

The cards show Received only after the transfer evidence matches. Open the explorer link belonging to your run.

4. Reopen without paying again

Keep the run URL. Reloading it reads the same request; it does not send another payment. If a connection is interrupted, check the existing request before starting again. A new test must be selected explicitly.

If capacity is exhausted or the engine is unavailable, open a saved receipt or inspect the recorded proof. Those are earlier executions, not a fresh test.
