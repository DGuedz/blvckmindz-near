BLVCK MINDZ × NEAR / Overview

A track. An agreement. A payment.

BLVCK MINDZ helps collaborators see how a track’s income is divided and check the resulting payment.

Start with one payment

The public demo follows a prefilled participant sheet through a local calculation and a real NEAR testnet distribution. The recording sample divides 2.00 test tokens between a label, an artist and a beatmaker.

  1. See the agreed shares.
  2. Simulate the calculation.
  3. Distribute the fixed sample on testnet.
  4. Check the recipient amounts and this run’s transaction.
Try the demo →

What this proves

A successful, verified run shows that the configured test-token transfers match the expected recipients and amounts. It does not establish commercial royalties or legal ownership.

“Test USDC” is a project-issued token with no monetary value. It is not Circle USDC.
